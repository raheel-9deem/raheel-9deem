# Generated profile assets

`github-contributions.svg` and `github-overview.svg` are generated by
`scripts/generate_activity.py`.

The workflow checks GitHub activity every 30 minutes.

`github-contributions.svg` always represents exactly the rolling previous
365 calendar days. When a new day arrives, the oldest date automatically
drops out of the visible calendar.

The workflow only creates a Git commit when the generated data actually
changes, so it does not create pointless commits every 30 minutes.

Do not manually edit the generated SVG files.
